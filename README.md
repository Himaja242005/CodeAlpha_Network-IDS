# Network Intrusion Detection System

This project demonstrates a beginner-level Network Intrusion Detection System dashboard inspired by Snort and Suricata.

## Features

* Intrusion detection alerts
* Suspicious IP monitoring
* Firewall activity tracking
* Network traffic monitoring
* Response alerts and notifications
* Dashboard visualization

## Technologies Used

* HTML
* CSS
* JavaScript
